# ADR-0001: 全ローカルMDXを折りたたみ式サイドバーに掲載する

| 項目 | 内容 |
| --- | --- |
| Date | 2026-09-24 |
| Status | Accepted |

## Context

MDX/Gitを公開コンテンツのマスターとする方針へ変更した。現在は一部のローカルMDXだけをサイドバーに掲載し、残りはMap of Contentsやハブページから参照している。

Reflectリンク中心の構成では、リンク先の本文がリポジトリ内検索やAI向けMarkdownに含まれず、AIがコンテンツを一貫して参照しにくい。

ローカルページを探しやすくしながら、サイドバーの一覧性を保つ必要がある。

## Decision

全ローカルMDXをカテゴリ単位の折りたたみ式サイドバーに掲載する。Reflectなどの外部リンクはMap of Contentsに残す。

フラットなファイル構造と既存URLは変更せず、ページツリー上でカテゴリをグループ化する。表示中のページを含むカテゴリは自動で開く。

## Consequences

- ローカルページをサイドバーから直接探せる
- カテゴリを閉じることで、ページ数が増えても一覧性を保てる
- ページ追加時にサイドバーのカテゴリ設定も更新する必要がある
- Fumadocsのページツリーを仮想的にグループ化する実装が必要になる

## Other Options

- 主要ページだけをサイドバーに掲載する案は、ローカルページの発見性が低いため採用しない
- 外部リンクもサイドバーに掲載する案は、項目数が増え、サイト内ページと外部遷移の区別が難しくなるため採用しない
