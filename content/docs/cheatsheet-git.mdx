## Configuration

### Auto Squash Setup
```bash
git config rebase.autosquash true
```
Auto-squash設定により、`git commit --fixup` や `git commit --squash` でコミットした際に、`git rebase -i` で自動的に配置。

## .gitignore

.gitignoreが効かないとき（追跡済みファイルをキャッシュから削除）：

```bash
git rm -r --cached .
git add .
git commit -m ".gitignore is now working"
```

## Cache

### キャッシュ削除
```bash
# ファイル全体のキャッシュ削除
git rm -r --cached .

# ファイルを指定してキャッシュ削除
git rm -r --cached [ファイル名]
```
`.gitignore` に追加したファイルがすでにトラッキングされている場合に使用。
