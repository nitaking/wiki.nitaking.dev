## 家の中の子ども撮影

> F2 / 最低SS 1/250 / Auto ISO上限12800 / 顔瞳ON / CL連写

---

普段の室内子ども：**1/250**  
ずり這い・ハイハイ・手足が動く：**1/500**  
寝てる・抱っこで静か：**1/125〜1/250**  
作品っぽく少しブレも許す：**1/125**

---

晴れ屋外：**F2.8〜F4 / 1/500以上 / Auto ISO**  
曇り・日陰：**F2〜F2.8 / 最低SS 1/500**  
走る・手足の動き：**1/1000**  
街と人を一緒に残す：**F4〜F5.6 / 1/500**  
背景を溶かしたい：**F1.4〜F2 / 1/1000以上**

X-E5 + XF18mm F1.4なら、外の子ども・家族写真はかなり扱いやすい。僕ならまず **Aモード / F2.8 / Auto ISO上限6400 / 最低SS 1/500 / 顔瞳ON / CL連写** にする。

## XF35mm f1.4

- 外
  - 歩き・子ども・家族スナップ：**F2-2.8**
    - 止まってる人物：**F1.4〜F2 / 1/500**
    - 歩いてる子ども：**F2〜F2.8 / 1/500〜1/1000**
    - 走る・手足が速い：**F2.8 / 1/1000**
    - 街と人を両方残す：**F4 / 1/500**
- Base
  - **基本 F2.8 / 最低SS 1/500**
  - 余裕あるとF1.4に

## あえてブレにするとき

- **基本は1/125**
  - 室内で「気配は残したいけど、顔は破綻させたくない」→ **1/125**
  - 手足の動きだけ少し流したい → **1/125**
  - 歩いてる感じ・生活の揺れを出したい → **1/60**
  - かなり表現として流す、写真っぽいブレにする → **1/30以下**
